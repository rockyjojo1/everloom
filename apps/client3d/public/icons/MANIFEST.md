# Icon Manifest

This manifest lists all game UI icons needed for Everloom 3D with AI generation prompts ready for use.

## Icon Format
- **Format**: PNG, 512x512
- **Background**: Flat background (use dominant palette color)
- **Style**: Low-poly stylized fantasy, consistent with game aesthetic
- **Generation Tool**: AI image model (DALL-E, Midjourney, or Stable Diffusion recommended)
